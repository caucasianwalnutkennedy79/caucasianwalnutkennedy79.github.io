🤔 Frequently Asked Questions

Why do I need this tool?

Counterfeit "foreign" health products are a massive problem in global e-commerce. Many products claim to be imported from Germany, the US, or Australia, but are actually manufactured locally and packaged with fake brand claims. This tool gives you the power to verify claims yourself.

Is it legal to use?

Absolutely. This tool only accesses publicly available official databases, business registries, and public sales information. It's a legitimate due-diligence tool similar to what professional investigators use.

Is this software free?

Yes, this is an open-source project. You can download and use it freely. You can also contribute to its development on GitHub.

I'm not technical. Can I still use it?

Yes! We built this with everyday users in mind. The tool has a simple interface. Just enter a product name and read the results. No commands, no coding, no terminal.

Does it work on Mac or Linux?

The primary supported environment is Windows. However, because it's built on OpenClaw (Python-based), it can run on any system that supports Python — but for the best experience, we recommend Windows.

📝 How It Works Behind the Scenes

Curious about the technical magic? Here's a simple breakdown: this OpenClaw skill uses a combination of official government databases, international business registers, and scraped e-commerce data to build a "fingerprint" of the brand. When you enter a product, it compares the claims on the package against official data. If the brand isn't registered where they say it is, or if the product doesn't appear in official channels, the tool flags it.
